# 🌟 Featured Projects

## 🤖 RAG Chatbot

A Retrieval-Augmented Generation chatbot built using LangChain and Streamlit.

### Highlights

* 📄 Supports **PDF, TXT, DOCX, and CSV** document ingestion
* ✂️ Splits documents into chunks for efficient retrieval
* 🔎 Uses **ChromaDB** for semantic vector search
* 🎯 Uses contextual compression and **Cohere re-ranking**
* 🤖 Integrated **OpenAI, Google Generative AI, and Hugging Face**
* 🌐 Supports conversational and multilingual assistance

**Tech Stack:** Python · Streamlit · LangChain · ChromaDB · Cohere · OpenAI · Google Generative AI · Hugging Face

## 🧠 AI Candidate Screening & Interview System

An AI-powered candidate screening and interview system that uses **Retrieval-Augmented Generation** to analyze candidates against job requirements.

### Highlights

* 📄 PDF resume parsing and text extraction
* 🔎 Resume and job-description analysis
* 🧠 Embeddings and vector-based retrieval
* 🎯 Identifies matched and missing skills
* 🤖 Generates technical interview questions
* 💬 Evaluates candidate responses
* 📊 Provides candidate suitability analysis

**Tech Stack:** Python · FastAPI · RAG · LLM · OpenAI · ChromaDB · JavaScript · HTML · CSS
